出典と利用条件

独自RAVE試作。モデルの重みと配布条件を保持しています。

音色モデル: Water / IIL · Pond Brain。Intelligent Instruments LabがJenna SutelaのPond Brainのために制作。RAVEはAntoine Caillon、Philippe Esling / ACIDS・IRCAMによる研究です。水の録音で学習したRAVE実モデルの重みを使用しています。

IILのモデルカード / RAVE公式 / CC BY-NC 4.0

Djembe / Scyclone: Torsion Audioの公開RAVE実モデル（固定commit 2b1990c4ad04fec1981d21bdde94fdafbadb84e0）。出典・CC BY-NC条件。4個の潜在座標を公開し、35個のConvと4個のConvTransposeに状態保持を追加。全元initializerを保持し、元モデルに対して既知の追加遅延1360 samplesを検証しました。通常noiseでの長信号との小さな数値残差が残るため実験版です。

学習済みモデルは非商用利用・出典表示等の条件付きです。本アプリでは、元の4096 samples状態付きONNXへ潜在gain/bias入力を追加し、2048 samples用の固定shape・関連定数を調整しました。学習済み重みは変更していません。変更の再現スクリプト・元SHA-256・出力検証は配布フォルダに含みます。

Waterは16次元のうち6座標、Djembeは保持された4座標を操作します。PCA、音響的に命名された意味軸、Neutone Morphoとの同一性を主張しません。

Djembeの元モデルにもフルスケールを超えるraw出力があることを確認しました。独自アプリとして再生gainの初期値を4%とし、再生直前に±0.98のピーク上限を置いています。保存WAVはその前の音を32-bit floatで保持し、正規化・clipしません。

推論: ONNX Runtime Web 1.30.0 / Microsoft contributors / MIT。LICENSE / Third-party notices。モデルロード時にSHA-256とtensor契約を照合します。

音声はAudioWorkletとWorker内で処理します。HTTPサーバーは静的ファイル配信のみです。音声アップロード、プラグイン連携、サーバー推論は実装していません。マイクは開始時に要求し、停止時に解放します。

デモ入力はこの試作内で生成した和音・打音・ノイズです。音色変換に使用する学習済みRAVEモデルとは別の入力信号です。

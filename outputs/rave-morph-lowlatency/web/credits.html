独自RAVE試作。モデルの重みと配布条件を保持しています。

個人による非商用の研究・実験用プロトタイプです。モデルと第三者ライブラリーの条件は、それぞれの表示に従います。

モデルごとの出典・変更記録：Organ 512 / Organ 1024 / Water / Djembe

Organ / IIL · causal 512: Intelligent Instruments Labの公開学習済みモデルを、Victor ShepardsonのRAVE forkで読込みました。8-band×ratios[4,4,4,1]で元の圧縮率が512。48 kHz、128次元のposterior、checkpointに保存されたPCAを使用します。先頭6方向へのgain/bias差分を加え、残る座標も保持します。元のencoder/decoder/PQMF・学習済みAdaINを使い、36個の状態を明示したONNXへ変換。VAEの正規乱数入力は維持し、decoder noise moduleは元設定どおりありません。

OrganのチェックポイントSHA-256は218518cb0f7c2670a9cd3973c3e2972632893f599deacc851998b372a8f8a22e。重み正規化のfold前後の出力差は0。長い元native推論と512ごとの連続推論を同じ乱数で比較し、追加shift0でmax3.13e-7、ONNXとのmax4.02e-7を確認。これは元モデルの絶対的なDry/Wet時間合わせや物理往復遅延の測定ではありません。

Water は過去の比較実験です。公開元からの変換経路が未再現のため、現在の取得・変換手順には含めません。

過去の音色モデル: Water / IIL · Pond Brain。Intelligent Instruments LabがJenna SutelaのPond Brainのために制作。RAVEはAntoine Caillon、Philippe Esling / ACIDS・IRCAMによる研究です。水の録音で学習したRAVE実モデルの重みを使用しています。

IILのモデルカード / RAVE公式 / CC BY-NC 4.0

Djembe / Scyclone: Torsion Audioの公開RAVE実モデル（固定commit 2b1990c4ad04fec1981d21bdde94fdafbadb84e0）。出典・CC BY-NC条件。4個の潜在座標を公開し、35個のConvと4個のConvTransposeに状態保持を追加。全元initializerを保持し、元モデルに対して既知の追加遅延1360 samplesを検証しました。通常noiseでの長信号との小さな数値残差が残るため実験版です。

学習済みモデルは非商用利用・出典表示等の条件付きです。Waterでは、元の4096 samples状態付きONNXへ潜在gain/bias入力を追加し、2048 samples用の固定shape・関連定数を調整しました。学習済み重みは変更していません。変更の再現スクリプト・元SHA-256・出力検証は配布フォルダに含みます。

Waterは16次元のうち6座標、Djembeは保持された4座標を直接操作します。Organは保存されたPCAを使います。音響的に命名された意味軸やNeutone Morphoとの同一性は主張しません。

Djembeの元モデルにもフルスケールを超えるraw出力があることを確認しました。独自アプリとして再生gainの初期値を4%とし、再生直前に±0.98のピーク上限を置いています。保存WAVはその前の音を32-bit floatで保持し、正規化・clipしません。

推論: ONNX Runtime Web 1.30.0 / Microsoft contributors / MIT。LICENSE / Third-party notices。モデルロード時にSHA-256とtensor契約を照合します。

音声はAudioWorkletとWorker内で処理します。HTTPサーバーは静的ファイル配信のみです。音声アップロード、プラグイン連携、サーバー推論は実装していません。マイクは開始時に要求し、停止時に解放します。

デモ入力はこの試作内で生成した和音・打音・ノイズです。音色変換に使用する学習済みRAVEモデルとは別の入力信号です。
